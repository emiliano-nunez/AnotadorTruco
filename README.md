# Anotador de Truco

Anotador de puntos para el truco argentino, hecho con HTML, CSS y JavaScript puro (sin dependencias).

## Características

- Dos equipos con nombres editables (por defecto "Nosotros" y "Ellos").
- Puntos dibujados con fósforos, en cuadraditos de 5 como en papel.
- Partida a 15 o a 30 puntos (con división entre malas y buenas).
- Botones +1 / −1; también se puede tocar la zona de fósforos para sumar.
- Deshacer el último cambio.
- Aviso de ganador al llegar al límite.
- Guarda la partida en el navegador (no se pierde si recargás la página).

## Uso

Abrí `index.html` en cualquier navegador. Para usarlo desde el celular podés publicarlo con GitHub Pages
(Settings → Pages → Deploy from a branch).
